# vroo_net

Flutter plugin that joins the box's Wi-Fi and carries datagrams to the box and to the internet. The Kotlin and Swift sides stay thin, and the logic is in Dart. The design is in [architecture §4.4](../../docs/architecture.md), and the test commands are in [development.md](../../docs/development.md).

`example/` is a network-check screen for trying the plugin on a phone.
